FONTLOG for the Gauhtion font

This file provides detailed information on the Gaution font
Software.

This information should be distributed along with the Gaution
font and any derivative works.

Basic Font Information

Gaution has a jagged activity.

Designed by Klasky Wolf Lodge.

Gauhtion is a Unicode typeface family that supports languages that use
the Latin script and its variants.

More specifically, this release supports the following
Unicode ranges: Basic Latin, Latin-1, and Latin-2

To contribute to the project contact Brian J. Bonislawsky
at astigma@astigmatic.com
